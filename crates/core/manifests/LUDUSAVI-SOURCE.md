The bundled `ludusavi.json` is a reduced offline snapshot of the
[Ludusavi Manifest](https://github.com/mtkennerly/ludusavi-manifest),
downloaded on 2026-11-25 and converted by `scripts/import-ludusavi.py`.
The upstream data is compiled from PCGamingWiki and Steam metadata. See
`LUDUSAVI-LICENSE` for the upstream MIT license and copyright notice.
Only supported path placeholders are currently used by SaveSync.
