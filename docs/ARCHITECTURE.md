# Структура SaveSync

Демон координирует операции; desktop и Decky вызывают общий IPC-протокол.
В core находятся переносимые модели, use cases и реализации Backend.
Нативные UI-зависимости не проникают в core.

| Зона | Ответственность |
|---|---|
| `core/engine.rs` | публичные типы результатов, параметры движка |
| `core/engine/state.rs` | локальный индекс, applied, кеш и публикация доступных архивов |
| `core/engine/upload.rs` | создание новой версии или доставка существующей в канал |
| `core/engine/restore.rs` | выбор версии, проверки, safety backup и применение |
| `core/engine/destinations.rs` | сопоставление логических save locations между платформами |
| `core/engine/locks.rs`, `import.rs` | блокировки и импорт переносимого архива |
| `core/storage_paths.rs` | wire identifiers и переносимые имена файлов |
| `core/snapshot.rs` | формат ZIP, целостность, проверка назначения и извлечение |
| `core/lan/server.rs` | владение listener, ограничение клиентов и остановка |
| `daemon/commands/` | команды CLI: custom, remote, backup, serve |
| `daemon/runtime/` | сервисы catalog, history, channels, configuration, sync и backups |
| `daemon/ipc.rs` | transport и dispatch; не содержит sync-алгоритм |
| `app/daemon_client.rs` | порт `DaemonClient`, IPC-адаптер и валидация результатов |
| `app/application/` | состояние приложения, фоновые jobs и представления |
| `app/config_form.rs` | преобразование и проверка формы конфигурации |
| `app/presentation.rs`, `theme.rs` | форматирование и оформление |

Backend принимает операции над архивами и индексом. Engine зависит от trait,
а Runtime выбирает файловый, облачный или LAN-адаптер. Desktop зависит от
`DaemonClient`, что позволяет проверять его действия без desktop automation.
Модули `tests.rs` сохраняют доступ к нужным внутренним деталям, не раздувая
файлы реализации.

Новая версия сначала сохраняется как архив; индекс канала не рекламирует
недоступные локальному кешу архивы из другого канала. История из старого
состояния догружается из исходного канала. Недоступный старый архив
регистрируется в stderr и не блокирует применение доступной актуальной версии.
Параллельные записи разных устройств пока требуют CAS; локальная сериализация
запросов демона этого не заменяет.

Политики и инфраструктура остаются разными обязанностями. Добавление OAuth,
защищённого pairing или CAS должно развивать соответствующие адаптеры, а не
переносить эти обязанности в UI-контроллер или CLI-dispatch.
