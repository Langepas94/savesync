# Установить SaveSync на PC и Steam Deck и проверить перенос

Нужны Windows PC, Steam Deck и одна домашняя сеть. Этот сценарий не требует облачного аккаунта, OAuth, Rust или сборки из исходников. Начните с отдельного тестового файла, затем попробуйте копию настоящего сейва.

## 1. Какие файлы взять

Из одного комплекта проверки возьмите:

- **На Windows:** `Windows/savesync-setup-dev.exe`.
- **На Steam Deck:** `SteamDeck/SaveSync-SteamDeck.run`.

Рядом лежат файлы `.sha256` для проверки целостности. Windows-установщик пока не подписан. Оба пакета должны быть из одного комплекта: не смешивайте прежнюю сборку `fb3b031` с новой.

Если файлы находятся только на PC, скопируйте файл `SaveSync-SteamDeck.run` на флешку и затем на Deck, в папку Downloads.

## 2. Установить на Windows

1. Закройте игры. Если уже запускали переносную сборку SaveSync, остановите её командами из PowerShell в её папке:

   ```powershell
   .\savesync-daemon.exe stop
   .\savesync-app.exe --quit
   ```

2. Запустите `savesync-setup-dev.exe`. Если Windows показывает предупреждение, проверьте, что запускаете именно полученный тестовый файл.
3. Установите программу с настройками по умолчанию. Права администратора не нужны.
4. Откройте SaveSync из меню «Пуск».
5. Дождитесь надписи «демон работает». Если вместо неё «Демон не запущен», нажмите «Запустить SaveSync».

Установщик размещает программу в `%LOCALAPPDATA%\Programs\SaveSync`. Настройки и история лежат отдельно, в `%APPDATA%\savesync`.

## 3. Установить на Steam Deck

1. Нажмите STEAM → Power / Питание → Switch to Desktop / Перейти в режим рабочего стола.
2. Откройте Dolphin и скопируйте `SaveSync-SteamDeck.run` в Downloads.
3. Правой кнопкой по файлу → Properties / Свойства → Permissions / Права доступа → разрешите выполнение файла как программы. Это может понадобиться после скачивания или копирования.
4. Откройте файл и выберите запуск, если Dolphin спросит. Подтвердите установку в появившемся окне.
5. После сообщения об успехе откройте **SaveSync** через меню приложений и проверьте надпись «демон работает».

Пароль администратора и изменение системного раздела не нужны. Установщик сам распакует файлы и запустит пользовательскую службу. При ошибке отправьте файл `savesync-install.log` из домашней папки.

Для необязательной установки Decky-плагина отдельно понадобится архив `savesync-steamos.tar.gz` из того же комплекта.

## 4. Включить LAN на обоих устройствах

В SaveSync на **PC и Deck**:

1. Откройте «Подключения».
2. Для чистого теста оставьте пустыми поля локальной папки и облачных токенов. Если уже были подключения, сначала запишите настройки.
3. Отметьте «Включить LAN». Переключатель сохраняется сразу.

На Windows разрешите доступ SaveSync к **частной** домашней сети, если появится запрос брандмауэра. PC не должен спать во время переноса.

## 5. Соединить Deck с PC

1. На PC нажмите «Показать мой PIN».
2. На Deck нажмите «Найти устройства», затем «Выбрать» рядом с PC.
3. На Deck введите PIN с PC и нажмите «Сопрячь».
4. Сравните код проверки, который появится на обоих устройствах автоматически.
5. Если код совпадает, нажмите «Коды совпадают» на **обоих** устройствах.
6. Проверьте, что устройство появилось в списке «Доверенные устройства».

Если поиск не находит PC, перенесите адрес из блока с PIN в поле «Адрес второго устройства» на Deck.

Если SAS не совпал, нажмите «Отклонить» и повторите соединение. Успешного ввода PIN недостаточно: нужны оба подтверждения SAS.

## 6. Проверить перенос без настоящих сейвов

### Подготовить PC

Откройте обычный PowerShell. Вставьте весь блок:

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\SaveSync-Trial" | Out-Null
Set-Content -LiteralPath "$env:USERPROFILE\SaveSync-Trial\slot.sav" -Value 'from-pc'
& "$env:LOCALAPPDATA\Programs\SaveSync\savesync-daemon.exe" custom add 'SaveSync Trial' --path '<home>/SaveSync-Trial/*.sav'
```

Этот пример предполагает стандартный путь установки. Если выбрали другой каталог, замените путь к программе.

### Подготовить Deck

В Konsole вставьте:

```sh
mkdir -p "$HOME/SaveSync-Trial"
printf '%s\n' 'deck-initial' > "$HOME/SaveSync-Trial/slot.sav"
~/.local/bin/savesync-daemon custom add 'SaveSync Trial' --path '<home>/SaveSync-Trial/*.sav'
```

### Перенести PC → Deck

1. В приложении на обоих устройствах нажмите «Игры» → «Обновить».
2. Найдите **SaveSync Trial**. Нажмите «Синк» на PC, дождитесь окончания.
3. Нажмите «Синк» у этой игры на Deck, дождитесь окончания.
4. На Deck проверьте файл:

   ```sh
   cat "$HOME/SaveSync-Trial/slot.sav"
   ```

Ожидается `from-pc`. Если видите `deck-initial`, перенос не прошёл — пришлите результат синхронизации.

### Перенести Deck → PC

На Deck:

```sh
printf '%s\n' 'from-deck' > "$HOME/SaveSync-Trial/slot.sav"
```

Нажмите «Синк» на Deck, затем на PC. На PC проверьте:

```powershell
Get-Content -LiteralPath "$env:USERPROFILE\SaveSync-Trial\slot.sav"
```

Ожидается `from-deck`. Повторный «Синк» без изменения файла должен вернуть `up_to_date`.

## 7. Открыть SaveSync из Gaming Mode

Основной перенос работает без Decky. Для доступа к desktop-приложению из Gaming Mode:

1. В Desktop Mode откройте Steam.
2. Games / Игры → Add a Non-Steam Game / Добавить стороннюю игру.
3. Выберите SaveSync. Если его нет, нажмите Browse / Обзор и укажите `/home/deck/.local/bin/savesync-app`.
4. Добавьте программу. В её свойствах **не включайте Proton**: это Linux-приложение.
5. Вернитесь в Gaming Mode и откройте SaveSync в библиотеке, в разделе сторонних игр.

Для управления интерфейсом используйте раскладку контроллера с мышью/трекпадом. Этот способ тоже требует физической проверки на вашем Deck. Если окно не открылось, проверьте работу в Desktop Mode и пришлите результат.

## 8. Установить плагин в шторку Decky

Это отдельный способ доступа из Gaming Mode. Если Decky Loader ещё нет, установите стабильную версию по [официальной инструкции Decky](https://github.com/SteamDeckHomebrew/decky-loader#-installation). После установки убедитесь, что в меню кнопки **…** появилась иконка Decky.

Для локальной тестовой версии SaveSync вернитесь в Desktop Mode. Откройте Konsole **в распакованной папке `savesync-steamos`**, где лежит каталог `decky-plugin`, и выполните:

```sh
test -d "$HOME/homebrew/plugins" && test ! -e "$HOME/homebrew/plugins/SaveSync" && test ! -L "$HOME/homebrew/plugins/SaveSync" && test -f ./decky-plugin/plugin.json && test -f ./decky-plugin/dist/index.js && sudo cp -a ./decky-plugin "$HOME/homebrew/plugins/SaveSync" && sudo systemctl restart plugin_loader
```

Команда рассчитана на стандартный путь Decky Loader и первую установку SaveSync-плагина. Она копирует готовый плагин и перезапускает Decky. Нужен пароль администратора Deck. Если каталог `SaveSync` уже существует, сначала остановитесь и используйте обновление существующего плагина; не копируйте новую папку внутрь старой.

Если команда не выполняется, не меняйте права системных каталогов: пришлите её вывод. SaveSync в Desktop Mode остаётся доступным. Для нестандартной установки Decky путь отличается.

Вернитесь в Gaming Mode → **…** → Decky → SaveSync. Проверьте статус демона, наличие тестовой игры и кнопку синхронизации. Конфликты разрешаются в desktop-приложении.

## 9. Попробовать настоящую игру

1. Выберите одну игру, установленную на обоих устройствах. Скопируйте её сейвы отдельно на каждом устройстве.
2. Закройте игру на обоих устройствах. На время теста избегайте параллельного переноса через Steam Cloud.
3. В SaveSync нажмите «Обновить» на обоих. Убедитесь, что игра найдена и ключ игры одинаковый.
4. На устройстве с нужным прогрессом нажмите «Синк». Затем нажмите «Синк» на втором.
5. Запустите игру на втором устройстве и проверьте прогресс.
6. Сохранитесь, закройте игру и повторите перенос в обратную сторону.

Если игры нет в списке, пришлите название и магазин. Не добавляйте наугад всю папку игры. Перенос Windows/Proton/native Linux зависит от формата сейва и правил конкретной игры.

В 1.0.0 синхронизация ручная: **закрыть игру → «Синк» на источнике → «Синк» на получателе → открыть игру**.

## Что прислать

Достаточно: на каком шаге остановились, что нажали, точный текст ошибки или скриншот. Добавьте версии Windows/SteamOS и Decky, если проверяли шторку. Если всё прошло, напишите: «установка PC/Deck — ок; перенос туда-обратно — ок; Gaming Mode/Decky — ок или не проверял».

PIN, токены, пароли и полный профиль программы не присылайте.
