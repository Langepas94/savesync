# SaveSync 1.0.0: первый запуск

SaveSync переносит сохранения между компьютером и Steam Deck. В версии 1.0.0 синхронизация запускается кнопкой. Перед игрой скачайте прогресс, после выхода из игры отправьте его.

Сейчас это кандидат версии 1.0.0. Подписанный публичный релиз ещё не выпущен. Для первого знакомства достаточно Windows и локальной папки: облако и второй компьютер не нужны.

## 1. Запустите приложение

**Windows:** если получили установщик `savesync-setup-dev.exe`, установите его и откройте SaveSync из меню «Пуск». Это неподписанная тестовая сборка.

Если получили папку с программой, оставьте `savesync-app.exe` и `savesync-daemon.exe` рядом. Откройте `savesync-app.exe`. Установка и запуск от администратора не нужны. Такая папка использует обычный профиль SaveSync; слово «portable» не означает отдельные настройки.

Если SaveSync уже работает, завершите старое приложение через трей и остановите старый демон перед сменой сборки. В PowerShell из папки старой программы:

```powershell
.\savesync-daemon.exe stop
.\savesync-app.exe --quit
```

Не запускайте две разные сборки одновременно. Повторный запуск приложения открывает уже работающее окно.

**Steam Deck:** перейдите в Desktop Mode. Распакуйте готовый Linux-пакет `savesync-steamos.tar.gz`, откройте Konsole в распакованной папке `savesync-steamos` и выполните:

```sh
./install-steamos.sh
```

Откройте SaveSync в меню приложений. Windows-файлы `.exe` для этого не подходят. Подробности: [установка SteamOS](STEAMOS-DELIVERY.md).

Вверху окна должна появиться надпись «демон работает». Демон — фоновая часть программы, которая переносит файлы. Если он не запущен, нажмите «Запустить SaveSync».

## 2. Подготовьте одну игру

1. Выберите игру с ненужным тестовым сохранением.
2. Один раз запустите игру, сохранитесь и полностью выйдите из неё.
3. В SaveSync откройте «Игры» и нажмите «Обновить».
4. Найдите игру в списке. Нажмите «Детали».

Игра может быть установлена, но ещё не иметь сохранений. В таком случае SaveSync не создаёт пустую версию. Если игры нет в списке, используйте [ручное правило](USER-GUIDE.md#если-игра-не-найдена).

Первую проверку можно выполнить вообще без настоящей игры: [пошаговый тест с текстовым файлом](TRY-1.0.0.md).

## 3. Выберите папку для синхронизации

1. Создайте пустую папку, например `C:\SaveSync-Test\storage`.
2. Откройте «Подключения».
3. В блоке «Локальная папка / USB (fs)» укажите полный путь к этой папке.
4. Оставьте остальные подключения выключенными или пустыми.
5. Нажмите «Сохранить» и дождитесь сообщения о сохранении.

Это хранилище SaveSync. **Не указывайте здесь папку с оригинальными сейвами игры.** Не редактируйте содержимое хранилища вручную.

Для двух устройств нужна одна доступная обоим папка: например, одна флешка. Две разные локальные папки с одинаковым названием не соединяются автоматически. Для передачи по Wi-Fi используйте [LAN](USER-GUIDE.md#соединить-pc-и-steam-deck-по-wi-fi).

## 4. Включите резервные копии

1. Откройте «Настройки».
2. В поле «Папка бэкапов» укажите отдельную папку, например `C:\SaveSync-Test\backups`.
3. Оставьте число копий пустым: программа хранит до 10 копий на игру.
4. Нажмите «Сохранить».
5. Вернитесь к игре: «Детали» → «Сделать бэкап».

Внизу окна появится путь к файлу `.savesync-backup`. Проверьте, что файл существует. Для самой первой проверки дополнительно скопируйте оригинальный сейв средствами Windows или файлового менеджера Deck.

## 5. Нажмите «Синк» у одной игры

Дождитесь окончания операции. Возможные сообщения:

| Сообщение | Что произошло |
|---|---|
| `uploaded` | Сохранение отправлено в выбранное хранилище. |
| `applied` | Версия из хранилища записана в папку игры. |
| `up_to_date` | Изменений нет. Повторная копия не нужна. |
| `no_saves` | Локальных сейвов и доступной удалённой версии ещё нет. |
| `conflict` | Есть разные версии. Выберите нужную в «Деталях». |
| `locked` | Операцию блокирует другое устройство. Повторите позже. |
| `error` | Операция завершилась ошибкой. Скопируйте текст из нижней строки. |

В «Деталях» появится история версий. Повторный «Синк» без изменения сейва должен вернуть `up_to_date`.
