# Проверяем SaveSync 1.0.0 самостоятельно

Этот сценарий использует отдельный текстовый файл вместо настоящего игрового сейва. Для проверки нужны Windows и папка со свежими `savesync-app.exe` / `savesync-daemon.exe`. Убедитесь, что старая сборка остановлена: [первый запуск](QUICKSTART.md).

## Тест 1. Отправка и повторная синхронизация

1. Создайте три разные папки: `C:\SaveSync-Test\saves`, `C:\SaveSync-Test\storage`, `C:\SaveSync-Test\backups`.
2. В Блокноте создайте файл `C:\SaveSync-Test\saves\slot.sav` с текстом `progress-1`. При сохранении выберите тип «Все файлы», чтобы не получить `slot.sav.txt`.
3. Откройте PowerShell в папке с программой. Выполните:

   ```powershell
   .\savesync-daemon.exe custom add "SaveSync Trial" --path "<home>/SaveSync-Trial/*.sav"
   ```

4. Для одинакового правила на Windows и Deck тестовые сейвы будут лежать в домашней папке. В PowerShell выполните:

   ```powershell
   New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\SaveSync-Trial"
   Copy-Item -LiteralPath 'C:\SaveSync-Test\saves\slot.sav' -Destination "$env:USERPROFILE\SaveSync-Trial\slot.sav"
   ```

   Дальше редактируйте именно `%USERPROFILE%\SaveSync-Trial\slot.sav`. Исходный файл в `C:\SaveSync-Test\saves` остаётся запасной копией.

5. Запустите приложение. В «Подключениях» укажите `C:\SaveSync-Test\storage`, нажмите «Сохранить».
6. В «Настройках» укажите папку бэкапов `C:\SaveSync-Test\backups`, нажмите «Сохранить».
7. Во вкладке «Игры» нажмите «Обновить». Найдите `SaveSync Trial`.
8. Нажмите «Детали» → «Сделать бэкап». Проверьте файл `.savesync-backup` в папке бэкапов.
9. Нажмите «Синк» у тестовой игры. Ожидается `uploaded` и первая версия в истории.
10. Ещё раз нажмите «Синк». Ожидается `up_to_date`; число версий не увеличивается.

Если у вас уже есть другие подключения, SaveSync использует и их. Для чистого опыта заранее запишите настройки и временно оставьте один тестовый канал. Не проверяйте «Синхронизировать всё» на настоящих играх до завершения теста.

## Тест 2. Изменение и откат

1. Измените текст в `%USERPROFILE%\SaveSync-Trial\slot.sav` на `progress-2`, сохраните и закройте Блокнот.
2. Нажмите «Синк». Ожидается `uploaded` и новая версия.
3. В «Деталях» у первой версии нажмите «Применить».
4. Откройте файл снова. Ожидается `progress-1`.
5. Нажмите «Синк» ещё раз. Откат должен сохраниться; `progress-2` не должен вернуться сам.

Времена истории указаны в UTC. Для выбора смотрите также устройство и идентификатор версии.

## Тест 3. Перенос PC → Deck → PC

Этот шаг требует настоящего Deck. Если его нет под рукой, первые два теста уже дают полезную обратную связь.

1. Установите Linux-пакет на Deck и откройте SaveSync в Desktop Mode.
2. В Konsole выполните:

   ```sh
   mkdir -p "$HOME/SaveSync-Trial"
   ~/.local/bin/savesync-daemon custom add "SaveSync Trial" --path '<home>/SaveSync-Trial/*.sav'
   ```

3. Нажмите «Обновить». Игра может появиться только после появления первого файла: для ручного правила без Steam ID создайте начальный тестовый файл:

   ```sh
   printf '%s\n' 'deck-initial' > "$HOME/SaveSync-Trial/slot.sav"
   ```

4. Снова нажмите «Обновить». На обоих устройствах должен быть ключ `custom:savesync-trial`.
5. Соедините устройства по [гайду LAN](USER-GUIDE.md#соединить-pc-и-steam-deck-по-wi-fi). На PC для этого теста очистите поле локальной папки и сохраните, чтобы остался только LAN. На Deck также оставьте один LAN-канал.
6. На PC нажмите «Синк», затем на Deck нажмите «Синк».
7. На Deck прочитайте файл:

   ```sh
   cat "$HOME/SaveSync-Trial/slot.sav"
   ```

   Ожидается `progress-1`. Первое получение заменяет начальный файл Deck с защитной копией.

8. На Deck измените файл:

   ```sh
   printf '%s\n' 'progress-from-deck' > "$HOME/SaveSync-Trial/slot.sav"
   ```

9. Нажмите «Синк» на Deck, затем на PC.
10. Откройте файл на PC. Ожидается `progress-from-deck`.

## Тест 4. Конфликт

Выполняйте после успешного теста 3. Оба устройства должны начинать с одного прогресса.

1. На PC измените тестовый файл на `pc-choice`, на Deck — на `deck-choice`.
2. Нажмите «Синк» на PC, затем на Deck. Должен появиться `conflict`.
3. Откройте на Deck «Детали». Убедитесь, что видны обе ветки.
4. Выберите ветку Deck, в том числе если она помечена «применена»: нажмите «Применить».
5. Синхронизируйте Deck, затем PC.
6. Проверьте: на обоих устройствах файл содержит `deck-choice`, конфликт исчез.

Если конфликт не возник, пришлите последовательность действий и историю: это результат проверки, а не повод удалять профиль.

## Что прислать после проверки

Скопируйте шаблон и заполните только то, что успели проверить:

```text
Сборка: имя папки/установщика и версия
Устройства: Windows ..., SteamOS ...
Канал: папка / флешка / LAN / Google / Яндекс
Тест 1: прошёл / не прошёл / не проверял
Тест 2: прошёл / не прошёл / не проверял
Тест 3: прошёл / не прошёл / не проверял
Тест 4: прошёл / не прошёл / не проверял
Шаг, на котором возникла проблема:
Что нажал:
Что ожидал:
Что произошло:
Точный текст сообщения внизу окна:
Ключ игры и выбранная версия, если есть:
Что непонятно в интерфейсе или гайде:
```

Полезен скриншот окна с ошибкой и историей. Не присылайте токены, пароли, PIN, файлы хранилища секретов или полный профиль программы. Если проблема только с настоящей игрой, добавьте её название, магазин и тип запуска на Deck: native Linux или Proton.

После тестов ручное правило можно убрать:

```powershell
.\savesync-daemon.exe custom remove custom:savesync-trial
```

Это удаляет правило поиска, а не оригинальные файлы или историю. Для обычных игр верните нужные подключения и нажмите «Сохранить».
