# SaveSync 1.0.0: как пользоваться

Начните с [первого запуска](QUICKSTART.md). Здесь описаны кнопки текущего приложения и действия после настройки.

## Перед игрой и после игры

Синхронизация в 1.0.0 ручная. Автозапуск SaveSync при входе в Windows не означает автоматический перенос сейвов. Автобэкап по расписанию тоже не запускает синхронизацию.

При переходе с PC на Deck:

1. Сохранитесь на PC и полностью закройте игру.
2. Нажмите «Синк» у игры на PC. Дождитесь окончания без ошибки.
3. На Deck нажмите «Синк» у той же игры. Дождитесь `applied` или `up_to_date`.
4. Запустите игру на Deck и проверьте прогресс.
5. После игры на Deck повторите порядок в обратную сторону.

Первые разы переносите одну игру. «Синхронизировать всё» запускает операции для всех найденных игр и всех подключённых каналов. Если один канал недоступен, другой может уже успешно принять данные: читайте весь результат.

Не запускайте игру на двух устройствах одновременно. Игра может перезаписать восстановленные файлы при выходе. Для тестовой игры со Steam Cloud избегайте одновременной работы двух систем синхронизации; сначала сохраните независимую копию сейва.

## Соединить PC и Steam Deck по Wi-Fi

Нужна одна локальная сеть. Подключение к облаку и OAuth для LAN не нужны. Оба устройства должны быть включены, а SaveSync должен работать.

### Включите LAN

На **обоих** устройствах:

1. Откройте «Подключения».
2. Отметьте «включить LAN-канал».
3. Оставьте порт `47660`. Поле «Пиры» пока можно оставить пустым.
4. Нажмите «Сохранить» и дождитесь завершения.

Если Windows спрашивает о доступе к сети, разрешите SaveSync работать в вашей частной сети. Для соединения используется UDP-порт `47660`. Гостевая Wi-Fi сеть может запрещать устройствам видеть друг друга.

### Сопрягите устройства

1. На PC нажмите «Показать PIN на 2 минуты».
2. На Deck нажмите «Найти устройства».
3. У найденного PC нажмите «Выбрать адрес».
4. Введите на Deck шестизначный PIN с PC и нажмите «Сопрячь».
5. Нажмите «Обновить доверие» на **обоих** устройствах.
6. Сравните показанный SAS — второй шестизначный код проверки.
7. Если SAS совпадает, нажмите «SAS совпадает — доверять» на **обоих** устройствах.
8. Ещё раз обновите доверие. Должна появиться надпись «Доверенное устройство».

PIN и SAS выполняют разные задачи. PIN вводят при соединении. SAS сравнивают после соединения. Если SAS различается, нажмите «Отклонить» и начните сопряжение заново.

Если PC не найден, в поле «Адрес» на Deck введите IPv4 компьютера с портом, например `192.168.1.10:47660`. Адрес PC можно посмотреть в Windows: PowerShell → `ipconfig` → «IPv4-адрес» активного Wi-Fi/Ethernet. Не используйте `127.0.0.1`: это адрес самого устройства.

После подтверждения адрес PC автоматически добавляется в исходящие подключения Deck. Обратное сопряжение для обычного обмена не обязательно. В этой схеме **Deck обращается к PC**:

- PC → Deck: «Синк» на PC, затем «Синк» на Deck.
- Deck → PC: «Синк» на Deck, затем «Синк» на PC.

Если после первой операции история второго устройства ещё показывает прежнее состояние, повторите «Синк» на устройстве, которое должно получить прогресс. Для LAN PC должен оставаться доступным во время обмена. Временное выключение экрана не должно переводить PC в сон.

При смене IP повторите сопряжение по новому адресу и проверьте поле «Пиры»: удалите устаревший адрес, если он остался. Кнопка «Забыть» отзывает доверие. Для полного удаления связи повторите действие на втором устройстве и удалите старые адреса из поля «Пиры», затем сохраните настройки.

## Использовать флешку

1. Создайте на флешке отдельную папку хранилища, например `SaveSyncStorage`.
2. На PC укажите её в «Подключения» → «Локальная папка / USB (fs)» и сохраните настройки.
3. Закройте игру и нажмите «Синк» на PC.
4. Дождитесь завершения и безопасно извлеките флешку.
5. Подключите её к Deck. Укажите **эту же папку** через её путь на Deck и сохраните настройки.
6. Нажмите «Синк» на Deck.

Буква диска Windows и Linux-путь будут разными — это нормально. При смене устройства подключайте флешку до синхронизации. Путь нужно брать из файлового менеджера, а не копировать Windows-путь на Deck.

## Подключить облако

В кандидате нет встроенных зарегистрированных приложений Google/Яндекс. Поэтому первый вход пока требует подготовки `oauth-apps.json`: [инструкция OAuth](OAUTH.md). Без client ID кнопка входа не настроит облако сама. Для первого теста проще использовать папку или LAN.

Когда OAuth уже настроен на каждом устройстве:

1. Откройте «Подключения».
2. Нажмите «Подключить Google через браузер» или «Подключить Яндекс через браузер».
3. В открывшемся браузере войдите в аккаунт и разрешите доступ.
4. Вернитесь в SaveSync. Дождитесь сообщения «Облако подключено».
5. На втором устройстве войдите в **тот же аккаунт того же провайдера**.
6. Переносите прогресс кнопкой «Синк», как описано выше.

Браузер должен открываться на устройстве, где начат вход. На SteamOS вход удобнее выполнять в Desktop Mode. Доступность хранилища секретов после перехода в Gaming Mode требует отдельной проверки: [OAuth и Secret Service](OAUTH.md).

Токены, client secrets и пароль хранилища не присылайте в обратной связи. Поля ручных токенов нужны для расширенной настройки; новичку их заполнять не требуется.

## Выбрать версию при конфликте

Конфликт означает, что на устройствах появились разные изменения. SaveSync сохраняет обе ветки и ждёт выбора.

1. Закройте игру на обоих устройствах.
2. Откройте «Игры» → нужная игра → «Детали».
3. Найдите сообщение «Конфликт» и список версий.
4. Сравните устройство и время создания. Время в списке указано в **UTC**, а не в местном часовом поясе.
5. Нажмите «Применить» у версии с нужным прогрессом. Можно выбрать и версию с отметкой «применена».
6. Дождитесь «версия применена».
7. Нажмите «Синк» на этом устройстве, затем на втором. При LAN учитывайте порядок выше.
8. Откройте игру и проверьте результат.

«Голова» означает последнюю версию отдельной ветки. «Применена» означает версию, ранее записанную на это устройство. Эта отметка не гарантирует, что игра после этого не изменила файлы.

Программа не показывает содержимое игрового прогресса и не объединяет игровые файлы по смыслу. Выбирайте целую версию. Прежние версии остаются в истории.

## Вернуть более старое сохранение

1. Закройте игру.
2. Нажмите «Детали» → «Сделать бэкап», чтобы отдельно сохранить текущее состояние.
3. В истории найдите нужную старую версию и нажмите «Применить».
4. Дождитесь завершения. Откат создаёт новую запись истории.
5. Нажмите «Синк», затем синхронизируйте второе устройство.
6. Проверьте результат в игре.

Файлы слотов, которых не было в выбранной версии, могут исчезнуть при восстановлении. Программа сохраняет защитные копии перед заменой. Не прерывайте операцию и не редактируйте её служебные файлы.

Если ошибка содержит `RestorePublicationPending`, локальные файлы уже восстановлены, но отправка результата не закончилась. Верните доступ к каналу и повторите «Синк».

## Создать и перенести резервную копию

Укажите «Настройки» → «Папка бэкапов», нажмите «Сохранить». Затем: «Игры» → «Детали» → «Сделать бэкап». Внизу окна будет полный путь к `.savesync-backup`.

Бэкап — отдельный переносимый файл. История — версии внутри SaveSync. Папку бэкапов держите отдельно от хранилища синхронизации. Если нужна постоянная архивная копия, скопируйте файл в другое место: ограничение числа копий удаляет старые бэкапы.

Импорт бэкапа пока выполняется командой. На Windows откройте PowerShell в папке программы:

```powershell
.\savesync-daemon.exe backup import "D:\Backups\имя-файла.savesync-backup"
```

На Deck:

```sh
~/.local/bin/savesync-daemon backup import "/полный/путь/имя-файла.savesync-backup"
```

Подставьте настоящий путь к файлу. Нужен хотя бы один настроенный канал. Импорт добавляет версию в историю; он **не восстанавливает файлы игры сразу**. После импорта откройте игру в SaveSync и нажмите «Детали» → «Применить» у импортированной версии. Игра должна быть найдена сканером, а правило её сохранений — настроено.

## Если игра не найдена

Сначала запустите игру, создайте сейв, выйдите и нажмите «Обновить». Встроенная база содержит 17 игр; некоторые другие Steam-игры обнаруживаются по данным Steam. Все игры автоматически не гарантируются.

Для игры вне базы можно добавить ручное правило через PowerShell из папки программы:

```powershell
.\savesync-daemon.exe custom add "My Test Game" --path "C:/Games/MyTestGame/saves/*.sav"
```

На Deck:

```sh
~/.local/bin/savesync-daemon custom add "My Test Game" --path "/home/deck/MyTestGame/saves/*.sav"
```

Замените путь на настоящую папку сейвов. `*.sav` подходит только если ваши сейвы имеют такое расширение. Не указывайте весь диск, домашнюю папку или папку игры целиком. Затем нажмите «Обновить».

На обоих устройствах используйте **одно имя**, чтобы получить одинаковый ключ игры, например `custom:my-test-game`. Пути при этом могут различаться. Для настоящих сейвов Windows/Proton/Linux может потребоваться правило с одинаковым логическим `location`: [схема манифестов](manifests-schema.md). Простое ручное правило само по себе не гарантирует переносимость между платформами.

## Если что-то не работает

| Проблема | Что попробовать |
|---|---|
| «Демон не запущен» | Нажмите «Запустить SaveSync». Проверьте, что оба исполняемых файла одной сборки находятся рядом. |
| «Канал синхронизации не настроен» | Укажите папку или включите LAN и нажмите «Сохранить». |
| «Папка бэкапов не задана» | Задайте её в «Настройках» и сохраните. |
| `no_saves` | Создайте сохранение в игре, выйдите и нажмите «Обновить». Проверьте путь правила. |
| LAN не видит устройство | Проверьте сеть, частный профиль Windows, UDP-порт, сон PC. Попробуйте ручной IPv4. |
| PIN больше не подходит | Создайте новое приглашение. Оно действует две минуты. |
| Сопряжение прошло, синхронизации нет | Подтвердите одинаковый SAS на обеих сторонах. Проверьте адрес в поле «Пиры». |
| `conflict` | Выберите версию в «Деталях». Для Decky перейдите в Desktop Mode. |
| Ошибка OAuth или хранилища секретов | Скопируйте текст ошибки. Проверьте настройку OAuth; для первого теста используйте LAN. |
| Результат ещё старый | Закройте игру, синхронизируйте источник, затем получателя. Проверьте, что это одна игра и один канал. |

Надпись «синхронизировано» в карточке отражает известную историю. Чтобы проверить изменения в сети и на диске, нажмите «Синк» и прочитайте результат.

Профиль Windows: `%APPDATA%\savesync`. Профиль Deck по умолчанию: `~/.local/share/savesync`. Не удаляйте профиль для исправления ошибки: там история и настройки. При отчёте не отправляйте весь профиль без проверки на секреты.

## Decky и закрытие окна

Decky-плагин необязателен. Для начала проверьте desktop-приложение. Готовый Linux-пакет содержит каталог `decky-plugin`; установка зависит от используемого Decky Loader и описана в [доставке SteamOS](STEAMOS-DELIVERY.md). Плагин не заявлен как опубликованный в Decky Store.

После установки в Gaming Mode откройте Quick Access → SaveSync. Там доступны статус, ручная синхронизация и сопряжение LAN. Конфликты разрешайте в desktop-приложении.

На Windows крестик сворачивает окно в трей, если трей успешно создан. Открыть окно и завершить приложение можно через значок рядом с часами. Демон работает отдельно: закрытие окна само по себе не останавливает его. На Deck демон работает как пользовательская служба.
