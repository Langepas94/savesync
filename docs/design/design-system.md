# SaveSync — Дизайн-система

Кроссплатформенная синхронизация сейвов (аналог Steam Cloud). Стек: Rust (egui/iced/Tauri) — дизайн нейтрален к фреймворку, все стили выражены через токены.

> v2 (фидбек заказчика): упрощение — минимум действий на первых экранах, облако и LAN как независимые каналы, убраны лимиты трафика, добавлены бэкапы.

## 2. Типографика

- Семейство: Segoe UI / system-ui.
- Десктоп: база 14 px; H1 — 20 px/600, заголовки панелей — 15 px/600, мета — 12–12.5 px.
- Шторка Decky: база 14.5 px, заголовок 17 px, цифры PIN — 40 px/800.
- Пути папок — моноширинный `code`, цвет `--accent`.

## 3. Отступы и сетка

- Шаг 4 px; карточки: padding 12–16 px, радиус 6 px (десктоп) / 10–12 px (шторка).
- Десктоп: сайдбар 190 px + контент, сетка игр `minmax(340px, 1fr)`, gap 14 px.
- Шторка: колонка 360 px, тач-зоны ≥ 64 px, кнопки ≥ 56 px.
- Модал конфликта: 720 px, две колонки-сравнения, выбранная версия — рамка `--accent`.

## 4. Каналы синхронизации: независимые, необязательные

Принцип v2: **облако и локальная сеть — не шаги визарда и не связаны между собой**. Экран «Подключения» — две независимые карточки с бейджем «необязательно»:

- **☁ Облако** — Яндекс.Диск / Google Drive, синхронизация между любыми устройствами.
- **📡 Локальная сеть** — pairing по 4-значному PIN (TTL ~5 мин) + автообнаружение устройств (mDNS), ПК ↔ Steam Deck без интернета.

Пользователь настраивает любое из двух, оба или ни одного — в последнем случае работают **локальные бэкапы**. Никаких stepper'ов и обязательных шагов.

## 5. Бэкапы

- **В карточке игры** — кнопка «📦 Создать бэкап»: снапшот сейвов в файл (`.ssbak`) в заданную папку или на USB; результат подтверждается toast'ом с путём.
- **В настройках** — раздел «Бэкапы»: авто-бэкапы по расписанию (выкл / ежедневно / еженедельно), папка хранения (допускается съёмный диск), retention — сколько копий на игру хранить (3 / 5 / 10 / все), импорт из файла.
- **В шторке** — только индикация: строка «✓ Бэкап создан: сегодня, 06:00». Никакого управления бэкапами с Deck.

## 6. Состояния (state machine)

`idle → syncing → synced | conflict | error`; отдельно `offline` (глобальный) и `local-only` / `cloud-only` (на игру).

- **syncing**: спиннер, прогресс-бар 4 px, кнопка неактивна, повторный тап игнорируется.
- **conflict**: баннер + чип; разрешение только явным выбором победителя; проигравшая версия сохраняется в истории. На шторке — только индикатор «разрешается на ПК».
- **error/offline**: индикатор демона в шапке/сайдбаре гаснет, Sync блокируется.
- Мутации подтверждаются toast'ом (~3 с).

## 7. Навигация геймпадом (Decky QAM)

- D-pad — roving-фокус, обводка 3 px `--accent`; `A` — выбрать, `B` — назад, `LB/RB` — вкладки.
- PIN-экран: цифры 58×76 px, клавиатура 3×4 с сеточной навигацией.
- Тач: все интерактивы ≥ 56 px, без hover-only поведения.
- Минимум текста: одна CTA, статусы — иконки + одна строка мета.

## 8. Различия платформ

| | Десктоп (Win11 / SteamOS) | Шторка Decky (360 px) |
|---|---|---|
| Структура | 3 раздела: Мои игры · Подключения · Настройки | 2 вкладки: «Синхр.» · «Связать» |
| Главный экран | Поиск + «Синхронизировать всё» + сетка игр; действия — внутри карточки игры | Только: кнопка Sync, баннер конфликта, индикация бэкапа, список сейвов |
| Конфликт | Полный resolver (сравнение версий) | Только индикатор |
| Бэкапы | Создание, расписание, retention, импорт | Только индикация «бэкап создан» |
| Подключения | Облако и LAN — независимые карточки | Только PIN-pairing (вкладка «Связать») |
| Ввод | Мышь + клавиатура | Геймпад first, тач |

Статус демона на Deck — в шапке шторки, отдельной вкладки «Статус» нет.

## 9. Файлы мокапов

- `desktop-app.html` — список игр, экран «Подключения» (облако + LAN независимо), карточка игры (синхронизация, история, бэкап, конфликт), настройки (папки, расписание, бэкапы).
- `decky-panel.html` — шторка QAM 360 px, 2 вкладки; стрелки/Enter эмулируют геймпад.
